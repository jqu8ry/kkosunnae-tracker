# 유설Seol 꼬순내 추적기

## 1.9.75 설치 안내

기존 사용자는 업데이트 후 홈에서 소식 바구니와 나뉜 다시보기를 소개하는 카드를 한 번 볼 수 있습니다.

유설Seol의 치지직 방송 시작과 치지직 커뮤니티·디스코드의 새 글을 알려 주는 데스크톱 Chrome용 확장 프로그램입니다. 최근 활동과 주간 발자국에서 같은 방송의 공개 다시보기 제목과 시작 시각을 확인할 수 있습니다. 최근 활동과 홈 요약에는 추적기가 새로 발견한 소식이 먼저 표시됩니다. 최근 활동은 발견한 날끼리 묶고, 왼쪽 열에는 시각만 표시합니다. 늦게 발견한 방송·글은 제목 아래에 원래 시작·작성 시각을 함께 보여줍니다. 처음 설치할 때 불러온 과거 기록은 원래 날짜로 표시하며, 주간 발자국은 방송 시작일 기준입니다. 확인된 분할 영상은 한국시간 방송 시작일의 다시보기에서 부별로 선택합니다. 일부 영상이 비공개가 되어도 확인된 부 번호는 유지합니다.

홈에서 **지금 확인**을 누르면 방송과 새 글을 조회합니다. 성공한 항목은 확인을 마친 시각부터 설정한 주기로 다시 확인합니다. 커뮤니티와 디스코드는 같은 주기를 쓰므로 두 곳이 모두 성공했을 때 함께 갱신됩니다. 치지직 커뮤니티의 재시도 대기가 끝나면 수동으로 다시 확인할 수 있어요. 재시도를 기다리는 동안 다른 출처에서 오류가 발생하거나 복구되면 버튼 아래 결과도 함께 바뀝니다. 모든 출처가 정상으로 돌아오면 평소 추적 상태가 다시 표시됩니다.

### 처음 설치할 때

1. 데스크톱 Chrome 120 이상에서 ZIP을 보관할 폴더에 풉니다. 압축을 푼 뒤에도 이 폴더를 유지하세요.
2. Chrome 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다. 확장 프로그램 카드에서 **1.9.75**를 확인하세요.
4. 툴바의 확장 프로그램 메뉴에서 **유설Seol 꼬순내 추적기**를 엽니다. 첫 화면의 **Chrome 알림 켜기**를 눌러 안내에 따라 허용하세요. **알림은 나중에**를 선택해도 팝업의 안내에서 다시 켤 수 있습니다.

기존 ZIP 설치판을 업데이트하려면 **같은 Chrome 프로필과 같은 설치 폴더**를 사용하세요. 새 ZIP의 내용을 기존 폴더에 덮어쓰고 `chrome://extensions`에서 추적기 카드의 **새로고침**을 누릅니다. 기존 설치를 유지하면 저장된 설정과 최근 활동을 이어서 사용할 수 있습니다. 웹스토어로 설치한 사용자는 Chrome을 통해 스토어 업데이트를 받습니다.

### 사용하기

- **홈**에서 현재 방송 상태와 다음 확인까지 남은 시간을 확인합니다. 새로 설치하면 방송은 5분마다 확인하며 새 방송을 감지하면 방송 화면을 자동으로 엽니다. 이미 열린 방송 탭이 있으면 그 탭을 앞으로 가져옵니다. 설정에서 **백그라운드에서 열기** 또는 **알림만 받기**로 바꿀 수 있습니다.
- **새 글 알림**을 켜면 치지직 커뮤니티와 디스코드 ‘공지사항’, ‘학기중에는-뭐하나요’ 채널을 기본 30분마다 함께 확인합니다. 디스코드 글 여러 건을 감지하면 묶음 알림을 누르고 최신순 목록에서 읽을 글을 고릅니다. 원문을 보려면 해당 서버와 채널에 접근할 수 있는 디스코드 계정으로 로그인하세요.
- **최근 활동**에는 최신 20건이 표시됩니다. 주간 기록의 발자국은 한국시간 기준 방송을 **시작한 날**, 필름 옆 숫자는 클립을 **만든 날**의 개수입니다. 지난 방송에서 오늘 만든 클립은 오늘 칸에 들어갑니다. 발자국을 눌러 방송·다시보기를 열거나 필름 숫자를 눌러 클립을 고를 수 있습니다. 확인된 0개는 흐린 ×0으로 표시합니다.
- **룰렛 확률표**를 열면 룰렛별 참여 키워드, 1회 금액과 항목별 확률을 확인할 수 있습니다. 표를 보는 동안 30초마다 갱신하며 **지금 갱신**으로 직접 확인할 수도 있습니다. 꺼진 룰렛의 키워드 복사는 비활성화됩니다.
- **설정**에서 방송 및 새 글 확인 주기, 방송 열기 방식, 화면 모드와 받을 알림을 바꿀 수 있습니다. **테스트 알림**으로 Windows 배너를 확인하고, **가이드 다시보기**로 처음 사용 안내를 다시 열 수 있습니다.

### 권한과 동작 범위

Chrome의 예약 기능으로 조회하고 해당 Chrome 프로필에 설정과 최근 활동을 저장합니다. 방송·영상은 치지직에서, 룰렛과 디스코드 글 정보는 추적기 전용 중계 서버에서 조회합니다. Chrome 알림과 치지직 커뮤니티 접근은 기능을 켤 때 요청하는 선택 권한입니다. Windows에서도 Chrome 알림이 허용돼 있어야 배너를 볼 수 있습니다.

Chrome이 완전히 종료됐거나 PC가 절전 중이면 정기 조회는 다음 실행·복귀 후 재개됩니다. 그동안 끝난 방송은 서비스에 남아 있는 정보 범위에서 확인합니다. 영상이 비공개되거나 삭제되면 방송 기록은 남고 시청할 수 없는 다시보기 버튼은 숨겨집니다.

### 1.9.16 테스트판 변경 사항

방송 조회가 실패하면 홈에 ‘놓친 방송 확인 지연’을 표시합니다. 주간표에서 아직 조회 중인 빈 날짜는 ‘확인 중’, 조회에 실패한 빈 날짜는 ‘확인 못함’으로 표시합니다. 이미 확인한 다시보기와 클립은 계속 열 수 있습니다. 룰렛 확률표를 열어 두면 참여 키워드도 30초마다 다시 확인합니다.

### 1.9.15 테스트판 변경 사항

설정 탭에 알림을 한 행에 하나씩 표시합니다. 왼쪽에서 알림 이름과 설명을 읽고 오른쪽 스위치로 켜거나 끌 수 있습니다. ‘백그라운드에서 열기’를 선택하면 ‘탭을 열 때 알림도 받기’가 같은 목록의 첫 행에 나타납니다.

### 1.9.13 테스트판 변경 사항

최근 활동은 모든 종류를 합쳐 최신 20건을 저장합니다. 방송 발자국에서는 이번 주와 지난주를 선택할 수 있습니다. 요일은 날짜 표시이며 발자국이나 그 아래 방송 문구를 누르면 방송을 열 수 있습니다. 필름과 숫자를 누르면 그날 만든 클립 목록이 펼쳐집니다. 새 글에는 출처 아이콘을 표시하고 홈의 자동 추적 아래에는 놓친 방송 알림 상태를 먼저 표시합니다.

### 1.9.12 테스트판 변경 사항

이번 주 방송 발자국에서 필름이나 옆의 숫자를 누르면 그날 만든 클립이 최신순으로 펼쳐집니다. 제목을 누르면 해당 클립이 새 탭에서 열립니다. 발자국을 눌러서는 기존처럼 방송이나 다시보기를 열 수 있습니다.

### 1.9.11 테스트판 변경 사항

룰렛 확률표의 각 탭에 1회 금액을 표시합니다. 탭을 선택하면 해당 룰렛의 참여 키워드를 확인하고 복사할 수 있습니다. 확률표가 갱신될 때 뚜봇의 공개 시청자 페이지에서 키워드 설정도 조회합니다. 키워드를 다시 확인할 수 없으면 같은 룰렛에서 마지막으로 확인한 값과 확인 날짜를 표시합니다. 키워드가 해제됐다고 확인되면 복사 버튼을 숨깁니다.

### 1.9.10 테스트판 변경 사항

주간 발자국은 한국시간 기준 방송을 시작한 주와 요일에 표시합니다. 지난주부터 이어진 방송은 홈에서 LIVE로 확인할 수 있습니다. 클립 수가 갱신돼도 선택 중인 다시보기 버튼의 키보드 포커스가 유지됩니다. 설정 버튼은 글자를 한 줄로 유지하고, 디스코드 글 목록을 Esc로 닫으면 최근 활동으로 포커스가 돌아옵니다.

### 1.9.9 테스트판 변경 사항

설정의 두 알림 항목을 나란히 표시할 때 제목과 설명은 위에서 시작하고 스위치는 세로 중앙에 놓입니다. 최근 활동 탭에서는 주간표 위의 중복 제목을 제거했습니다.

### 1.9.8 테스트판 변경 사항

최근 활동의 주간표에서 필름 옆에 `×6`처럼 그날 만든 클립의 정확한 개수를 항상 표시합니다. 클립이 0개면 필름과 숫자를 모두 생략합니다.

### 1.9.7 테스트판 변경 사항

최근 활동의 주간표에 공개 클립을 만든 날을 필름으로 표시합니다. 지난 방송의 장면도 클립 생성일에 집계하며 방송 기록이 없는 날에도 표시합니다. 날짜는 한국시간 기준입니다. 민트는 1~2개, 청록은 3~5개, 금색은 6개 이상입니다. 필름에 마우스를 올리면 정확한 수를 확인할 수 있습니다. 최근 활동을 보는 동안 5분마다 갱신하며 조회 실패 시 1분 뒤 다시 시도합니다.

### 1.9.6 테스트판 변경 사항

처음 팝업을 열면 방송 확인 예약 준비가 끝난 뒤 복구 안내가 필요한지 판단합니다. 디스코드 글 목록이 보조 소형 창에 열렸을 때도 ‘닫기’를 누르고 Esc를 누르면 작업하던 창으로 돌아갑니다.

### 1.9.5 테스트판 변경 사항

디스코드 묶음 알림에서 글 목록을 열고 Esc를 한 번 누르면 목록이 닫히고 ‘최근 활동’으로 포커스가 돌아옵니다. Esc를 다시 누르면 추적기 팝업이 닫힙니다.

### 1.9.4 테스트판 변경 사항

이전 소식은 최근 활동 20건의 빈자리만 채웁니다. 디스코드 묶음 알림을 누르면 추적기 팝업 안에 글 선택창이 열립니다. 가장 최근 글이 1번이며, 읽을 글을 선택하면 디스코드 원문이 열립니다. 닫기나 Esc로 최근 활동에 돌아갈 수 있습니다.

홈에 룰렛 확률표·디스코드·소포담 바로가기를 추가했습니다. 방송 감지의 새 기본값은 **방송 화면 자동 열기**입니다. 1.8.32에서 업데이트하면 직접 선택한 방식과 최근 활동을 보존하며, 직접 선택하지 않은 사용자도 기존의 알림만 받기를 유지합니다. 신규 설치와 명시적 기본값 초기화에는 방송 화면 자동 열기를 적용합니다.

홈의 **룰렛 확률표**에서 **욕망의 룰렛(상시)**와 **이벤트 룰렛**을 선택할 수 있습니다. 표를 열면 바로 조회하고, 화면에 보이는 동안 이전 조회가 끝난 시점부터 30초마다 다시 확인합니다. 오른쪽 아래 **지금 갱신**을 누르면 즉시 확인하며 조회 중에는 중복 요청을 막습니다. 개발판은 추적기 전용 Worker를 통해 항목별 설정 확률을 받습니다. 조회에 실패하면 **뚜봇 원본 보기**에서 확인할 수 있습니다. 디스코드와 소포담 바로가기는 새 탭에서 열립니다. 설정의 ‘커뮤니티·디스코드 새 글 알림’ 스위치 하나로 치지직 커뮤니티와 디스코드 두 채널(공지사항, 학기중에는-뭐하나요)을 함께 켜거나 끕니다. 공통 기본 주기는 30분이며 이미 저장한 주기는 유지됩니다. Chrome 알림 및 치지직 커뮤니티 조회 권한이 필요합니다. 채널별 첫 조회에서는 최신 글을 최근 활동에 담습니다. 이후 새 글은 각각 기록하고 알림은 채널별로 묶습니다. 하나면 원문을 열고, 여러 건이면 최신순 목록에서 읽을 글을 고릅니다. 최근 활동은 전체 20건까지 표시하며, 묶음 선택 목록은 최근 100개 묶음까지 보관하고 새 묶음을 저장할 때 30일 지난 묶음을 정리합니다. 1.9.2에서 처음 전환하거나 서버 체크포인트가 갱신될 때는 채널의 최근 100건까지 대조합니다. 이후 한 조회에서 최대 500건을 처리하고 나머지는 다음 조회에서 이어갑니다. 알림 또는 최근 활동에서 원문으로 이동할 수 있습니다. 원문은 디스코드 계정의 접근 권한을 따릅니다.

**설정 → 상태 미리보기**에서 ‘추적 중’과 ‘LIVE’를 골라 두 상태의 고양이와 배지를 살펴볼 수 있습니다. 방송 중에는 ‘추적 중’, 방송을 기다리는 동안에는 ‘LIVE’가 먼저 열립니다. 미리보기는 실제 추적 설정과 알림에 영향을 주지 않습니다.

최근 활동의 **이번 주 방송 발자국**은 한국 시간 월요일부터 일요일까지 방송 시작일별로 표시합니다. 민트색 발자국을 누르면 확인된 다시보기가, 빨간 LIVE 발자국을 누르면 현재 방송이 열립니다. 하루에 방송이 여러 개면 원하는 방송을 고를 수 있습니다. ‘준비 중’은 종료된 방송의 다시보기 링크를 기다리는 상태입니다. ‘기록 없음’은 추적 기록이나 공개 다시보기를 찾지 못한 날입니다. 주간표 아래의 **방송** 필터는 보관된 최근 활동 중 방송 내역만 표시합니다.

### 1.8.32 변경 사항

첫 알림 안내 후 ‘30초 둘러보기’를 선택하면 홈의 추적 상태, 설정의 방송 시작 동작, 최근 활동을 차례로 살펴볼 수 있습니다. 언제든 건너뛰거나 설정의 ‘가이드 다시보기’로 돌아올 수 있습니다.

### 1.8.31 변경 사항

설정에서 화면 모드, 방송·커뮤니티 확인 주기, 방송 시작 동작을 고르는 동안 목록이 저절로 닫히는 문제를 수정했습니다.

### 1.8.30 변경 사항

방송 중에는 고양이가 앞발을 둥글게 흔들고 작은 동작으로 인사를 마칩니다. 알림이 꺼져 있어도 홈의 추적 카드에는 방송 상태의 색상이 표시되며, 알림 꺼짐은 상단 배너에서 확인할 수 있습니다.

### 1.8.29 변경 사항

홈의 방송 중 화면과 LIVE 미리보기에는 분홍 발바닥을 들어 인사하는 고양이(Emote_2.png)를 사용합니다. 방송 대기 중에는 꼬리를 문 고양이, Windows 알림에는 응원봉을 든 고양이가 보입니다.

### 1.8.28 변경 사항

최근 활동 필터는 전체·방송·새 글·알림 실패를 서로 다른 배경색으로 표시합니다. 마우스를 올리거나 키보드로 이동하면 테두리가 나타나고, 선택한 항목에는 진한 테두리와 체크가 표시됩니다.

‘추적 중’ 배지에는 발자국 세 개가 차례로 찍힙니다. 방송 대기 중에는 꼬리를 문 고양이가 두 번 우물거리고 잠깐 쉽니다. ‘설정 → LIVE 미리보기’에서 방송 중 카드와 애니메이션을 확인할 수 있습니다. 미리보기는 현재 추적 상태·기록·알림을 변경하지 않습니다.

### 1.8.27 변경 사항

홈의 ‘최근 방송’과 ‘최근 글’은 시각을 분까지 표시합니다. 최근 활동 필터는 항목별로 색과 모양을 구분합니다. 방송을 기다릴 때는 앉아 있는 고양이가, 방송 중에는 움직이는 고양이가 보입니다. Windows 알림에도 응원봉 그림을 사용합니다.

### 1.8.26 변경 사항

최근 활동의 ‘방송’에서 진행·종료·놓친 방송을 함께 볼 수 있습니다. ‘더 보기’는 현재 항목 아래에 내역을 추가합니다. 홈에서는 최근 방송 시작과 최근 글 작성 시각을 표시합니다. 잠시 쉬기는 5분 간격 슬라이더와 30분·1시간·3시간·6시간 빠른 선택을 지원합니다. 알림 허용 배너 오른쪽이나 설정 탭에서 Chrome 알림을 끌 수 있습니다. 테스트 알림은 누를 때마다 새로 발송합니다. 움직임 줄이기를 사용하면 발바닥·고양이 앞발·LIVE 점이 정지합니다.

### 1.8.25 변경 사항

첫 실행 홈은 ‘Chrome 알림을 켤까요?’ 카드에서 알림 설정을 안내합니다. ‘나중에’를 선택하면 추적 현황이 열립니다. Chrome 알림 권한이 없거나 Chrome에서 알림 차단을 확인한 경우에는 홈 카드를 코랄색으로 표시합니다. 소식 바구니의 전체·방송·치지직·디스코드 버튼을 누르면 해당 소식이 바로 표시됩니다. 저장된 알림 실패 기록이 있으면 제목 옆의 알림 오류에서 확인할 수 있습니다.

### 1.8.24 변경 사항

첫 실행 홈에서 **알림 켜기**를 누르면 Chrome 알림과 커뮤니티 조회 권한을 한 번에 요청합니다. 허용 후에는 첫 커뮤니티 조회를 기준으로 이후에 올라온 새 글부터 알립니다. **나중에**를 누르거나 요청을 거절하면 세 탭의 상단 안내에서 다시 시작할 수 있습니다. 설정에서 새 글 알림만 따로 끌 수 있으며, 이후 방송 알림 권한을 다시 허용해도 그 선택을 유지합니다.

### 1.8.23 변경 사항

최근 활동의 방송 필터에서 방송 기록을 확인할 수 있습니다. 게시글은 원문으로, 지난 방송은 다시보기로 이동합니다.

### 1.8.22 변경 사항

여러 창에 같은 방송이 열려 있으면 홈·최근 활동에서 누른 창의 탭을 먼저 엽니다. 방송 시작 알림을 누르면 마지막으로 사용한 일반 Chrome 창의 탭을 우선합니다. 최근 활동은 방송 중·종료·새 글·놓친 방송·알림 실패를 글자와 색상 배지로 구분합니다.

### 1.8.21 변경 사항

방송을 열 때 상태 조회가 끝난 직후 현재 탭 목록을 다시 확인합니다. 기다리는 동안 닫힌 라이브 탭은 새로 열고, 사용자가 직접 연 탭은 재사용합니다. 다른 페이지가 된 탭은 전환 대상에서 제외합니다. 홈에서 백그라운드 열기를 마치면 ‘방송 열기’로 키보드 포커스가 돌아옵니다. 사용자가 다른 버튼이나 탭으로 옮겼다면 그 위치를 유지합니다.

### 1.8.20 변경 사항

홈·최근 활동에서 라이브 열기를 누르면 선택한 방송이 아직 진행 중인지 확인합니다. 종료됐거나 다른 방송이 시작됐다면 원래 방송의 공개 다시보기로 연결합니다. 다시보기가 없으면 채널 영상 목록을 엽니다. 백그라운드 열기를 선택하면 현재 화면을 유지합니다.

방송이 교체되면 열기 메뉴를 닫고 키보드 포커스를 방송 열기 버튼으로 돌립니다. 종료되면 지금 확인으로 이동합니다. 방송 시작 알림에는 방송 제목과 한국시간 기준 시작 시각이 표시됩니다.

### 1.8.19 변경 사항

홈 배너의 고양이를 점선 원의 가로 중앙에 맞췄습니다. 일시 중지 조절기를 펼쳐 배너가 작아질 때도 원과 그림이 함께 줄어들고, 그림 하단은 배너에 붙어 있습니다.

### 1.8.18 변경 사항

추적을 재개하면 새 조회가 끝날 때까지 방송 상태를 확인 중으로 표시합니다. 홈과 최근 활동의 라이브 열기는 클릭한 방송이 계속 진행 중일 때 실행됩니다. 방송 시작 알림은 해당 방송의 ID를 기억하며 종료 후에는 다시보기를 확인합니다. 공개 다시보기를 찾지 못하면 채널 영상 목록을 엽니다.

최근 활동의 라이브·다시보기 버튼은 오른쪽 가운데에 표시됩니다. 키보드로 라이브 버튼을 선택한 상태에서 방송이 끝나면 포커스가 다시보기 버튼으로 이어집니다. 다른 탭 작업이 진행 중이어도 로딩 중인 다시보기 탭의 상태를 먼저 확인합니다.

### 1.8.17 변경 사항

홈에서 방송과 새 글의 추적 상태를 구분합니다. Chrome 알림 권한 창을 닫은 뒤 팝업을 다시 열면 요청한 탭에서 결과를 한 번 확인할 수 있습니다. 첫 안내에서 ‘나중에’를 선택하면 ‘알림 허용’ 버튼으로 키보드 포커스가 이어집니다.

최근 활동은 현재 방송과 일치할 때 ‘라이브 열기’를, 종료된 방송에는 ‘다시보기 확인’을 표시합니다. 해당 방송의 공개 다시보기를 확인할 수 없으면 유설의 다시보기 목록을 엽니다.

### 1.8.16 변경 사항

첫 실행 홈에서는 알림 설정을 안내합니다. 알림 권한이 없으면 홈·최근 활동·설정의 상단에서 허용할 수 있습니다. ‘알림만 받기’는 권한이 있으면 방송 시작을 알립니다. ‘탭을 열 때 알림도 받기’는 백그라운드에서 방송을 열 때만 표시합니다.

### 1.8.15 변경 사항

설정 탭에서 **기본값으로 초기화**를 누르고 확인하면 자동 추적을 켜고 일시 중지를 해제합니다. 방송 5분·커뮤니티 60분, 알림만 받기, 방송 시작 배너와 놓친 방송 알림 켜짐, Chrome 화면 모드 따르기가 적용됩니다. 최근 활동과 Chrome 알림·커뮤니티 접근 권한은 유지합니다. **취소** 또는 Esc로 확인창을 닫을 수 있습니다.

### 1.8.14 변경 사항

새 설치에서 방송은 5분마다, 커뮤니티는 새 글 알림을 켜면 60분마다 확인합니다. 방송 기본 동작은 알림만 받기이며 첫 팝업에서 알림 권한을 선택합니다. 세 탭의 제목 크기와 슬라이더 위치를 통일했습니다. LIVE 점은 천천히 깜빡이며 움직임 줄이기 설정을 따릅니다.

### 1.8.13 변경 사항

툴바에서는 손 흔드는 고양이가 더 크게 보입니다. 팝업 제목은 주아체를 사용하고 작은 글자와 조작 버튼은 시스템 글꼴로 표시합니다. 홈의 다음 자동 확인은 남은 시간만 표시합니다. 최근 활동은 항목 이름 옆에서 시간을, 오른쪽에서 열기 버튼을 확인할 수 있습니다.

### 1.8.12 변경 사항

팝업의 홈·최근 활동·설정에 민트 레모네이드 색상과 배민 주아체를 적용했습니다. 글꼴과 라이선스는 fonts 폴더에 포함되어 있습니다. 화면 모드는 기존 설정을 따릅니다.

### 1.8.11 변경 사항

손을 흔드는 마스코트를 크기별 확장 아이콘으로 제공합니다. 새 글 알림을 누른 뒤 게시글이 로딩 중이면 안내 알림에서 같은 글로 다시 이동할 수 있습니다. 최근 활동에서도 다시 누를 시점을 안내합니다. ‘알림만 받기’를 선택하면 설정 화면에서 Chrome 알림 권한을 바로 허용할 수 있습니다.

### 1.8.10 변경 사항

홈에서 ‘커뮤니티·디스코드 추적’ 옆의 ‘꺼짐’을 누르면 새 글 알림 권한을 요청합니다. 방송 중에는 라이트·다크 모드 모두 LIVE 배지와 방송 상태가 빨간색으로 표시됩니다.

### 1.8.9 변경 사항

조회 결과는 지금 확인 버튼 아래, 다시보기 안내는 해당 방송 아래에 표시합니다. 열린 팝업은 자동 탭 열기 상태를 다시 확인하며, 다시보기 재시도 알림 발송에 실패하면 최근 활동에 기록하고 재발송을 예약합니다.

### 1.8.8 변경 사항

- 다시보기 탭이 로딩되거나 이동 중이면 팝업에서 다시 시도할 시점을 알려 줍니다. Windows 놓친 방송 알림을 누른 경우에는 같은 방송을 다시 열 수 있는 안내가 표시됩니다.
- ‘지금 확인’은 방송·커뮤니티 조회 결과가 저장되면 완료를 표시합니다. 자동 라이브 열기는 방송 확인 영역에 별도로 표시합니다.

### 1.8.7 변경 사항

- 라이브·게시글·다시보기 탭을 열거나 전환하는 동안에도 방송과 커뮤니티 조회를 계속합니다. 같은 대상의 중복 탭 생성을 방지합니다.
- 추적을 끄거나 일시 중지하면 진행 중인 조회와 대기 중인 자동 방송 열기를 취소합니다. 커뮤니티 권한을 해제하면 해당 조회를 취소합니다.

### 1.8.6 변경 사항

- 목록 탭으로 전환하는 순간 다시보기 필터가 풀리면 후보를 다시 확인합니다. 다른 탭에 다시보기 필터가 남아 있으면 그 탭으로 이동합니다.
- 홈이나 최근 활동에서 라이브 탭을 열어 화면에 표시하면 남아 있던 Windows 재시도 안내가 사라집니다.

### 1.8.5 변경 사항

- 같은 Chrome 세션에서 추적기가 열었던 목록 탭들을 기억합니다. 최근 목록 탭을 닫아도 앞서 연 목록 탭이 남아 있으면 재사용합니다. 기존 탭 중 다시보기 필터가 있는 탭을 먼저 선택합니다.
- Windows 알림을 눌렀을 때 라이브 탭의 로딩이나 이동이 계속되면, 완료 후 클릭해 다시 시도할 수 있는 알림을 표시합니다.

### 1.8.4 변경 사항

- 치지직이 다시보기 필터를 비워도, 같은 Chrome 세션에서 추적기가 열었던 채널 목록 탭을 재사용합니다. 사용자가 선택한 필터나 주소는 그대로 둡니다.
- 팝업에서 라이브 탭을 열 때 로딩이나 탭 이동이 계속되면 완료 후 다시 시도하도록 안내합니다.

### 1.8.3 변경 사항

- 자동 재개 중 저장·예약 실패 시 즉시 다시 시도하고, 계속 실패하면 30초 간격의 별도 복구 예약을 유지합니다. 정상 복구되면 두 조회를 재개하며, 추적을 끄면 복구가 추적을 다시 켜지 않습니다. 팝업의 복구 안내와 **지금 복구**로 수동 재시도할 수 있습니다. Chrome 예약은 실행 상태에 따라 늦어질 수 있습니다.
- 팝업 최초 읽기 중 발생한 최신 설정·테마·활동 변경을 놓치지 않습니다. 테마 저장이 연속 실패해도 실제 저장된 화면 모드로 복원합니다.
- 알림 권한을 끈 직후 테스트 알림도 권한 허용 방법을 안내합니다. 설정 화면에 테스트 전 필요한 조치를 함께 표시합니다.
- 작은 보조 글자를 12px 이상으로 키우고, 확대 등으로 팝업 높이가 짧아진 경우 머리말과 여백을 줄였습니다. 기존 기능과 권한은 유지했습니다.

검수에서 다시보기 목록을 올바른 주소로 연 뒤 페이지 로딩 중 필터가 전체 영상으로 바뀌는 현상이 간헐적으로 관찰됐습니다. 이 경우 치지직 페이지에서 **다시보기** 필터를 선택해 주세요. 원인과 재현 조건은 별도 검증 보고서에 구분해 기록합니다.

### 1.8.2 변경 사항

- 일반 설정 저장 또는 예약 변경이 실패하면 이전 설정의 방송·커뮤니티 확인 예약을 복구합니다. 동시에 진행한 예약 변경이 모두 끝난 뒤 복구하여 늦은 작업이 복구 결과를 덮어쓰지 않도록 했습니다.
- 일반 설정의 늦은 응답은 과거 설정으로 화면을 되돌리지 않습니다. 자동 재개나 다른 화면에서 변경된 최신 저장 상태를 확인해 표시합니다.
- 설정·최근 활동·화면 모드와 권한 구조는 유지합니다. 같은 설치 폴더에 덮어쓰고 `chrome://extensions`에서 새로고침하세요.
- 심사 중인 웹스토어 패키지는 그대로 유지합니다. 검증 범위와 제한은 함께 제공하는 1.8.2 검증 안내에 기록합니다.

### 1.8.1 변경 사항

- 중지 시간 변경 후 추적을 끄거나 다른 설정을 바꿔도 늦게 도착한 중지 응답이 최신 화면 상태를 덮어쓰지 않습니다.
- 중지 상태를 저장하기 전에 자동 재개 예약을 확보합니다. 예약 또는 설정 저장이 실패하면 이전 설정과 예약을 유지·복원합니다.
- 재개 시각 안내를 슬라이더 안으로 모으고 **지금 재개** 버튼을 가까이에 배치했습니다. 슬라이더의 방향키 1분 조절 안내를 추가하고 정확한 확인 시각 글자를 키웠습니다.
- 기존 설정과 최근 활동 저장 형식, 권한은 그대로입니다. 같은 설치 폴더에 덮어쓰고 확장 프로그램을 새로고침하세요.
- 심사 중인 웹스토어 1.7.4 패키지는 변경하지 않습니다. 1.8.1의 검증 범위는 함께 제공하는 **1.8.1 검증 안내**를 확인하세요.

### 1.8.0 변경 사항

- 라이트/다크 화면을 보라색 계열로 정리하고 홈·최근 활동·설정 화면을 분리했습니다. 기존 기능과 설정 키를 유지합니다.
- 기본 상태에는 손 흔드는 캐릭터, 방송 중에는 앞발을 흔드는 캐릭터, 일시 중지/추적 꺼짐에는 꼬리를 안은 캐릭터를 표시합니다. 제공받은 원본 이미지를 패키지에 포함했습니다.
- 방송·커뮤니티 다음 자동 확인까지 남은 시간을 각각 표시합니다. 숫자에 마우스를 올리면 정확한 예정 시각을 확인할 수 있습니다. 초 단위 화면 갱신 자체는 추가 네트워크 조회를 하지 않습니다. Chrome 상태에 따라 실제 조회가 지연될 수 있습니다.
- 화면 용어를 자동 추적·추적 중·추적 꺼짐·추적 재개로 통일했습니다.
- 방송 중 **방송 열기**에서 **현재 화면 유지하고 열기(백그라운드)**와 **방송으로 이동하기(포그라운드)**를 선택합니다. 기존 탭을 재사용하며, 자동 감지 시 동작은 설정에 따릅니다.
- **잠시 쉬기** 슬라이더는 드래그 시 즉시 적용합니다. 1분~6시간을 1분 단위로 선택하고 0분은 즉시 재개합니다. 일시 중지 중에는 같은 바와 **남은 시간** 라벨이 줄어듭니다. 다시 드래그하면 그 시점부터 새 시간을 적용합니다.
- 이 설치 ZIP은 로컬 업데이트용입니다. 심사 중인 웹스토어 1.7.4 패키지는 변경하지 않았습니다.
- 아래 기존 버전 검증 기록은 해당 버전의 이력입니다. 1.8.0의 실제 재검증 범위와 제한은 함께 제공한 1.8.0 검증 안내를 확인하세요.
