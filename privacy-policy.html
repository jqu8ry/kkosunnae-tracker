꼬순내 추적기 개인정보처리방침

갱신일: 2026년 11월 21일 · 대상: 유설Seol 꼬순내 추적기 (버전별로 제공 기능이 다릅니다)

꼬순내 추적기는 유설Seol의 공개 방송과 커뮤니티 소식을 확인하고 알림 또는 해당 페이지로의 이동을 제공하는 비공식 도구입니다.

1. 처리하는 정보와 목적

  • 감시 사용 여부, 확인 주기, 방송을 열 방식, 알림 선택, 일시 중지·재개 시각, 화면 모드를 저장하여 사용자가 선택한 기능을 제공합니다.
  • 공개 방송 제목·상태·ID·시작/종료 시각, 공개 게시글 ID·작성 시각과 다시보기 메타데이터를 조회하여 새 소식 감지와 중복 방지, 다시보기 연결에 사용합니다. 게시글 본문이나 댓글은 저장하지 않습니다.
  • 마지막 확인 결과, 최근 활동과 알림 실패·재시도 상태를 로컬에 저장하여 팝업에 표시하고 감시를 이어갑니다.
  • 이미 열린 탭을 재사용하기 위해 허용된 치지직·네이버 사이트의 탭 URL과 탭 ID, 활성 여부, 로딩 및 창 상태를 일시적으로 확인합니다. 일반 방문 기록 API를 조회하거나 방문 이력을 축적하지 않습니다.

2. 저장 위치와 외부 통신

설정과 처리 기록은 기기의 Chrome 프로필에 저장됩니다. 확장 프로그램은 개발자 서버로 설정, 활동 기록 또는 탭 주소를 전송하지 않습니다. 광고·분석·추적 도구를 포함하지 않습니다.

방송과 다시보기는 api.chzzk.naver.com, 커뮤니티는 사용자가 해당 기능을 허용한 경우 apis.naver.com의 공개 API를 HTTPS로 조회합니다. 자동 API 요청에는 로그인 쿠키를 포함하지 않도록 설정돼 있습니다. 요청을 받는 서비스에는 일반적인 인터넷 통신에 필요한 IP 주소 등 연결 정보가 전달될 수 있으며, 해당 서비스의 처리에는 서비스 제공자의 정책이 적용됩니다.

룰렛 확률표를 제공하는 버전은 표를 열 때, 열린 동안 30초 간격으로, 또는 사용자가 갱신을 누를 때 전용 Cloudflare 중계 서버(seol-tracker-api.jqu8ry.workers.dev)에 접속합니다. 중계 서버는 뚜봇에서 두 룰렛의 이름·가격·항목·확률을 가져옵니다.

1.9.2부터 커뮤니티·디스코드 새 글 알림은 치지직 커뮤니티와 함께 켜거나 끕니다. 업데이트 시 기존 커뮤니티 새 글 알림이 켜져 있으면 디스코드 두 채널도 함께 확인합니다. Chrome 알림 및 치지직 커뮤니티 조회 권한이 필요합니다. 추적 중 사용자가 정한 공통 주기(기본 30분, 30~120분)마다 또는 지금 확인을 누르면 같은 서버에서 유설 서버의 공지사항과 학기중에는-뭐하나요 채널의 글 식별자를 확인합니다. 1.9.3부터 처음에는 채널별 최신 글 한 건을 이전 소식으로 표시하고 이후에는 마지막 조회 위치부터 새 글을 조회합니다. 자동 요청에는 채널명과 서버가 발급한 조회 위치 값이 포함될 수 있습니다. 식별자로 작성 시각과 원문 링크를 구성합니다. 확장 프로그램은 이를 기기에 저장해 중복 알림을 방지합니다. 중계 서버는 봇 인증으로 Discord API를 조회하며 글 본문·작성자·첨부 파일은 확장 프로그램에 제공하지 않습니다. 원문을 열면 디스코드의 로그인 상태와 채널 접근 권한이 적용됩니다. 이전 1.9.1 테스트판의 디스코드 조회는 별도 알림을 켰을 때 3분 간격으로 동작합니다.

중계 서버로 보내는 자동 요청에는 사용자 식별자·로그인 쿠키·설정·최근 활동을 포함하지 않습니다. 접속 과정에서 Cloudflare는 IP 주소 등 연결 정보를 처리할 수 있고, 운영 및 장애 확인용 요청 기록이 남을 수 있습니다. 중계 서버는 응답을 최대 30초간 캐시합니다. 뚜봇 키와 디스코드 봇 토큰은 서버에 보관합니다.

라이브·게시글·다시보기 페이지를 열면 Chrome이 치지직 웹사이트에 접속합니다. 이 웹페이지의 로그인·쿠키·재생과 데이터 처리는 웹사이트 및 브라우저 설정을 따르며, 확장 프로그램이 로그인 정보나 쿠키를 읽는 기능은 없습니다.

3. 공유와 이용 제한

개발자는 확장 프로그램을 통해 처리하는 정보를 판매하지 않습니다. 광고나 이용자 추적, 신용도 또는 대출 판단에 사용하거나 제공하지 않습니다. 정보는 위에 설명한 소식 확인·알림·탭 연결 기능에 필요한 범위에서만 처리합니다. Chrome 웹스토어 사용자 데이터 정책의 제한된 사용 요건을 준수합니다.

4. 보관과 삭제

1.9.3부터 묶음 알림에서 글을 선택할 수 있도록 채널 및 글 식별자와 감지 시각을 기기에 저장합니다. 최대 100개 묶음이며 새 묶음을 저장할 때 30일이 지난 목록을 정리합니다. 최근 활동은 최대 20건이며 새 기록에 따라 오래된 항목이 교체됩니다. 알림의 발송 유효기간은 감지 후 24시간입니다. 발송 성공·취소·기한 확인 등에 따라 대기 데이터가 정리되지만, Chrome이나 감시가 꺼져 있으면 정리는 다음 실행 시점까지 지연될 수 있습니다. 처리 결과는 최근 활동에 남을 수 있습니다. 설정과 마지막 처리 식별자는 기능을 유지하기 위해 보관합니다.

사용자는 팝업에서 감시와 알림을 끄고 선택 권한을 해제할 수 있습니다. 확장 프로그램을 Chrome에서 제거하면 해당 확장 프로그램의 로컬 저장 데이터가 삭제됩니다. 운영체제 알림 센터나 Chrome에 이미 열린 탭은 별도로 닫거나 지울 수 있습니다.

5. 선택 권한

Chrome 알림 권한은 알림 기능을 켤 때 요청합니다. 커뮤니티 조회 권한은 새 글 알림을 켤 때 요청합니다. 해당 권한을 허용하지 않아도 기본 라이브 탭 감지 기능을 사용할 수 있습니다. 알림 전용 모드는 알림 권한이 필요합니다.

6. 방침 변경과 문의

기능이나 데이터 처리 방식이 변경되면 이 방침과 웹스토어 공개 내용을 갱신합니다.
