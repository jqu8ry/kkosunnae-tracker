# 1.9.42 이후 세부 변경 내역

**1.9.43~1.9.75 · 33개 버전 · 누적 변경 111건**

각 항목은 해당 버전에서 사용자에게 달라진 기능, 동작 또는 문구 하나를 뜻한다. 같은 기능을 후속 버전에서 다시 다듬은 경우에는 각각 한 건으로 셌다. 테스트 반복, 예시 데이터 추가, ZIP 생성, 스토어 등록은 집계에서 제외했다.

[1.9.75 릴리스와 설치 파일](https://github.com/jqu8ry/kkosunnae-tracker/releases/tag/v1.9.75) · [1.9.75 검수 범위](1.9.75.md) · [전체 버전 이력](../../CHANGELOG.md)

## 1.9.75 · 2건

1. 방송 시작 시 ‘알림만 받기’ 배너에 클릭 결과를 적었다. 방송 중이면 라이브를 열고, 이미 끝났으면 다시보기를 찾는다.
2. 놓친 방송 배너에는 다시보기를 찾을 수 없을 때 채널의 영상 목록을 연다고 안내한다.

## 1.9.74 · 2건

1. 좁은 초기화 확인창에서도 ‘커뮤니티·디스코드 30분’과 ‘놓친 방송 알림’이 각각 한 줄에 놓이도록 했다.
2. 디스코드 묶음 알림의 글 선택창이 팝업 한가운데 열리도록 스크롤바 너비만큼 치우치던 위치를 바로잡았다.

## 1.9.73 · 1건

1. 업데이트 카드 문구를 ‘나뉜 다시보기는 1부·2부를 골라 봐요.’로 줄여 좁은 화면에서도 한 줄로 읽을 수 있게 했다.

## 1.9.72 · 3건

1. 첫 실행 카드에서 알림을 켜는 이유를 한 문장으로 안내한다.
2. 기존 사용자의 업데이트 카드에 소식 바구니와 분할 다시보기를 소개한다. 이전 안내를 이미 본 사용자도 새 안내를 한 번 볼 수 있다.
3. 첫 실행 카드와 업데이트 카드에서 나란히 놓인 버튼의 높이를 36px로 맞췄다.

## 1.9.71 · 2건

1. 초기화 확인창에서 기본값으로 돌아갈 설정을 다섯 줄로 나누고 초기화 후에도 유지되는 항목을 명시했다.
2. 둘러보기 1~3단계의 설명을 문장별로 나누고, 선택할 옵션과 그 결과를 짝지어 읽을 수 있게 했다.

## 1.9.70 · 1건

1. 설정에서 방송 감지 방식 세 가지의 설명을 각각 한 문장으로 줄였다. 13px 글자 크기를 유지하고 좁은 화면에서는 단어 경계에서 줄을 바꾼다.

## 1.9.69 · 1건

1. ‘잠시 쉬기’에서 드래그의 효과와 5분 단위 조절 방법을 각각 한 줄로 분리했다.

## 1.9.68 · 1건

1. 홈의 ‘커뮤니티·디스코드 추적’ 상태를 오른쪽에 붙여 배지의 끝이 ‘지금 확인’ 버튼과 나란히 놓이게 했다.

## 1.9.67 · 5건

1. 홈에서 ‘놓친 방송 알림’과 ‘커뮤니티·디스코드 추적’을 각각 고정된 자리에 표시해 켜짐·꺼짐에 따라 줄 수가 달라지는 현상을 줄였다.
2. 새 글 추적이 꺼져 있으면 홈의 회색 ‘꺼짐’ 버튼에서 다시 켤 수 있다.
3. 방송 감지 방식별 설명의 두 번째 문장은 다음 줄에서 시작해 단어가 어중간하게 잘리지 않도록 했다.
4. 홈의 ‘최근 활동’과 화살표 사이 간격을 8px로 늘렸다.
5. 오른쪽 위 설정 버튼을 제거하고 상단 ‘설정’ 탭으로 진입 경로를 통일했다.

## 1.9.66 · 1건

1. 주간 날짜 범위, 다시보기·클립 목록과 툴팁, 소식 바구니, 홈 요약에서 요일을 붙이는 날짜를 한국시간 기준 ‘11.21.(토)’ 형식으로 통일했다.

## 1.9.65 · 1건

1. 커뮤니티·디스코드 새 글 알림을 켤 때 권한과 다음 확인 예약을 함께 반영해 ‘예약 복구’ 안내가 잠깐 나타나 설정 줄이 밀리던 문제를 고쳤다.

## 1.9.64 · 1건

1. 설정에서 Chrome 알림을 켰을 때, 껐을 때, 권한 요청을 취소했을 때의 결과를 구분해 오른쪽 아래에 3초간 표시한다.

## 1.9.63 · 6건

1. 자동 추적을 바꿀 때 고양이 카드의 배경을 유지하고, 900ms 동안 카드를 기울였다 펴는 중간에 내용이 바뀌게 했다.
2. 추적 중에는 고양이 주변의 점선이 72초에 한 바퀴씩 회전한다.
3. 라이트 모드에서 고양이 둘레가 배경에 묻히지 않도록 점선을 짙은 금색으로 바꿨다.
4. ‘동작 줄이기’를 켜거나 홈 위에 대화상자를 열면 점선 회전을 멈춘다.
5. 주간 발자국의 필름에 마우스를 올리면 클립의 생성 날짜·요일·개수를 보여준다.
6. 설정 초기화 성공창은 ‘설정을 기본값으로 초기화했습니다.’라는 제목만 표시해 같은 내용을 두 번 읽지 않게 했다.

## 1.9.62 · 7건

1. 자동 추적 카드가 바뀌는 시간을 520ms로 늘렸다.
2. 소식 바구니에서 분류를 고르면 버튼은 즉시 선택되고 목록만 300ms 동안 부드럽게 나타난다.
3. 같은 날 여러 방송과 분할 다시보기가 섞여 있을 때 1·2부를 왼쪽 선으로 묶고 목록의 중복 제목을 제거했다.
4. 주간 발자국의 다시보기 버튼에 마우스를 올리면 날짜·요일과 고를 수 있는 항목 수를 보여준다.
5. 확인 주기나 방송 감지 방식을 저장하는 동안 선택한 값과 주변 설정을 화면에 유지한다.
6. 커뮤니티 권한을 확인하는 사이 새 글 알림 스위치가 직전 값으로 되돌아가 보이던 문제를 고쳤다.
7. 설정 화면에서 스크롤바 자리를 미리 확보해 내용이 변해도 가로 배치가 흔들리지 않게 했다.

## 1.9.61 · 2건

1. 사용자가 자동 추적 스위치를 직접 조작하면 고양이 카드가 살짝 뒤집힌다. 외부에서 상태가 바뀌거나 ‘동작 줄이기’가 켜져 있으면 즉시 반영한다.
2. 새 글 알림 권한을 요청하는 버튼과 요약 문구를 두 열로 나눠 아래 확인 시각이 밀리지 않게 했다.

## 1.9.60 · 1건

1. 방송과 새 글의 ‘마지막 확인’ 시각에 오늘·어제를 표시하고 그보다 오래된 기록에는 월·일을 쓴다. 팝업을 열어 둔 채 자정을 지나도 갱신된다.

## 1.9.59 · 3건

1. 고양이 카드의 위쪽 여백, 상태 배지 테두리, 설명 두 줄의 공간을 맞춰 추적 상태가 바뀌어도 스위치 위치를 유지한다.
2. 자동 추적 설정이 실제로 바뀌면 상태 문구와 고양이 그림이 220ms 동안 전환되도록 했다.
3. 설정을 바꾸는 중에는 이전 예약 정보를 근거로 ‘복구’ 안내가 잠깐 뜨는 일을 막았다.

## 1.9.58 · 9건

1. 상시·이벤트 룰렛의 참여 키워드에 같은 테두리·배경·글자색을 적용했다.
2. 키워드, 복사 버튼, ‘참여 불가’ 안내의 높이를 28px로 맞췄다.
3. ‘잠시 쉬기’ 옆의 남은 시간을 ‘283분’ 대신 ‘4시간 43분’처럼 표시한다.
4. 홈의 ‘마지막 확인’ 시각에서 초를 빼고 시·분까지만 표시한다.
5. ‘지금 재개’는 누르는 즉시 요청을 보내고, 성공하면 패널이 잠시 머물렀다가 부드럽게 닫힌다.
6. 분할 다시보기와 하루 여러 방송 선택창에서 중복 제목을 없애고 날짜·요일·개수를 한 제목에 모았다.
7. 커뮤니티 새 글 알림을 바꿀 때 상단의 Chrome 알림 버튼까지 함께 움직이지 않도록 했다.
8. 설정 저장 안내의 배경을 글자 너비에 맞춰 오른쪽 아래의 빈 공간까지 칠해지지 않게 했다.
9. 설정 저장에 성공하면 결과 문구를 3초 동안 보여준 뒤 기본 안내로 돌아간다.

## 1.9.57 · 11건

1. 룰렛 참여 키워드와 복사 버튼을 같은 줄에 맞췄다.
2. 꺼진 룰렛에서는 복사 버튼을 숨기고 그 자리에 참여할 수 없는 이유를 표시한다.
3. ‘지금 갱신’을 누르면 조회는 즉시 시작한다. 성공하면 로딩 표시를 최소 0.5초 보여준 뒤 ‘✓ 갱신 완료’를 1.5초간 표시한다.
4. ‘잠시 쉬기’의 직접 입력란을 없애고 슬라이더를 드래그하거나 방향키를 누를 때마다 5분씩 조절하게 했다.
5. 빠른 휴식 시간을 30분·1시간·3시간·6시간으로 바꿨다.
6. 테스트 알림 결과를 팝업 안의 대화상자에 표시해 설정 아래에 빈 안내 줄을 둘 필요가 없어졌다.
7. 설정 초기화 결과도 별도 대화상자에서 확인하도록 했다.
8. 설정 스위치를 저장할 때 주변 설정이 흐려지거나 이전 값이 뒤늦게 다시 나타나는 현상을 줄였다.
9. 이번 주와 지난주를 오갈 때 주간 기록에 180ms 전환 효과를 적용하고 ‘동작 줄이기’에서는 즉시 전환한다.
10. 클립 선택창의 중복 제목을 없애고 ‘11.23.(월) 클립 3개’처럼 생성 날짜·요일·개수를 한 번만 표시한다.
11. 소식 바구니의 글 작성 시각과 방송 시작 시각을 출처·유형 아래 같은 위치에 정렬했다.

## 1.9.56 · 6건

1. Chrome 알림 권한을 켜거나 끌 때 버튼에서 진행 상태와 결과를 확인할 수 있게 했다.
2. ‘백그라운드에서 열기’에 진행·완료 표시를 넣고, 새 탭을 열었을 때와 이미 열린 탭이 있을 때의 안내를 구분한다.
3. ‘잠시 쉬기’ 패널이 홈 위에 겹쳐 열려 아래쪽 항목이 밀리지 않게 했다.
4. 주간 다시보기·클립과 최근 활동의 분할 다시보기는 팝업 안의 선택창에서 고른다. Esc로 닫으면 원래 버튼으로 돌아간다.
5. 다시보기 확인에 성공하면 완료 상태를 민트색으로 강조한다.
6. 룰렛에서 키워드를 복사한 결과와 확률표를 갱신한 결과를 따로 표시한다.

## 1.9.55 · 4건

1. ‘탭을 열 때 알림도 받기’ 스위치에 다른 알림 스위치와 같은 180ms 전환 효과를 적용했다.
2. 최근 활동에서 ‘더 보기’를 눌러도 읽던 스크롤 위치가 유지된다.
3. 항목이 펼쳐지면 키보드 포커스를 첫 번째 새 항목에 둔다.
4. 새로 펼친 항목에만 150ms 동안 나타나는 효과를 적용하고 ‘동작 줄이기’에서는 바로 보여준다.

## 1.9.54 · 3건

1. 자동 추적·놓친 방송 알림·커뮤니티 및 디스코드 새 글 알림 스위치의 손잡이가 180ms 동안 움직이게 했다.
2. 룰렛 키워드 복사에 성공하면 고정 너비 버튼에 민트색 ‘✓ 복사 완료’가 부드럽게 나타나 1.5초간 머물렀다가 돌아간다.
3. 다른 룰렛을 고르거나 키워드가 바뀌면 이전 키워드의 복사 완료 표시를 즉시 지운다.

## 1.9.53 · 1건

1. 치지직이 재시도를 기다리는 중에도 다른 출처의 새 실패·복구 결과를 홈 상단에 반영해 하단 오류 안내와 일치시켰다.

## 1.9.52 · 3건

1. 치지직 커뮤니티의 재시도 대기가 끝나면 대기 안내를 해제하고 다시 조회할 수 있다고 표시한다.
2. 자동 재조회에 성공하면 홈에 평소 추적 상태 요약을 다시 표시한다.
3. 한 출처가 복구돼도 다른 출처에 남은 오류는 계속 보여준다.

## 1.9.51 · 3건

1. 수동 조회 중 추적을 끄거나 일시 중지하면 진행 표시를 즉시 지우고, 늦게 도착한 응답이 이전 상태를 되살리지 않게 했다.
2. 수동 조회에 성공하면 완료 표시 후 홈의 추적 상태 요약으로 돌아간다.
3. 조회할 수 있는 모든 출처가 대기 중이면 버튼도 만료 시각까지 ‘재시도 대기’로 표시한다.

## 1.9.50 · 3건

1. ‘지금 확인’의 조회는 누르는 즉시 시작하고 ‘확인 중’은 최소 1초간 표시해 빠른 응답도 알아볼 수 있게 했다.
2. 조회가 끝나면 아이콘을 체크로 바꾸고 ‘확인 완료’ 표시를 2초간 유지한다.
3. 완료 문구와 아이콘이 부드럽게 사라진 뒤 ‘지금 확인’으로 돌아간다. ‘동작 줄이기’에서는 효과를 생략한다.

## 1.9.49 · 8건

1. 소식 바구니의 전체·방송·치지직·디스코드 버튼을 같은 너비로 맞췄다.
2. 선택된 분류의 체크 표시를 없애고 색상으로 선택 상태를 보여준다.
3. 알림 오류 버튼에는 기본 테두리를 두고 선택할 때 붉은 계열로 강조한다.
4. 분류 버튼과 활동 목록에 같은 보라색 디스코드 아이콘을 적용했다.
5. 홈의 새 글 알림 상태 문구를 ‘알림 꺼짐’으로 줄였다.
6. 좁은 화면에서는 방송과 새 글 상태 카드를 세로로 배치해 제목과 상태가 잘리지 않게 했다.
7. ‘지금 확인’을 누르면 버튼 안에서 민트색 빛이 흐르고 조회 성공 후 ‘확인 완료’가 약 1초간 보이도록 했다.
8. 수동 확인 성공 시 다음 자동 확인을 다시 예약한다. 방송은 방송 조회 성공 시, 새 글은 치지직과 디스코드 두 채널이 모두 성공했을 때 갱신한다.

## 1.9.48 · 4건

1. 소식 바구니에 전체·방송·치지직·디스코드를 한 줄로 배치해 목록을 펼치지 않고 원하는 출처를 바로 고르게 했다.
2. 저장된 알림 오류의 건수를 누르면 오류만 볼 수 있고, 마지막 오류가 사라지면 전체 목록으로 돌아간다.
3. 첫 실행 둘러보기에서 새 소식 바구니 버튼으로 분류를 선택하는 방법을 안내한다.
4. 놓친 방송 알림에서 돌아오면 알림을 눌렀던 창에서만 최근 활동의 ‘전체’ 버튼으로 포커스를 한 번 복원한다.

## 1.9.47 · 5건

1. 최근 활동을 한국시간 기준으로 발견한 날끼리 묶고 날짜는 묶음마다 한 번만 표시한다.
2. 활동 한 줄에서 왼쪽에는 시각, 중앙에는 제목과 유형·원래 시각, 오른쪽에는 열기 버튼을 배치한다.
3. 처음 설치할 때 가져온 과거 기록은 ‘설치 전 소식’으로 구분한다.
4. 발견 시각을 알 수 없는 예전 기록이 섞인 날에는 ‘발견한 소식’ 대신 ‘활동’으로 표시한다.
5. 분류를 바꾸거나 ‘더 보기’를 눌러도 보이는 항목에 맞춰 날짜 제목을 갱신하고 같은 날짜를 반복하지 않는다.

## 1.9.46 · 5건

1. 홈의 최근 소식과 최근 활동은 추적기가 처음 발견한 시각이 최신인 순서로 보여준다.
2. 늦게 발견한 방송·게시글에는 발견 시각과 함께 원래 방송 시작 시각이나 글 작성 시각도 표시한다.
3. 처음 설치할 때 가져온 과거 소식은 설치일 대신 원래 날짜에 표시한다.
4. 발견 시각이 없는 예전 디스코드 기록에는 원문의 작성 시각을 사용한다.
5. 같은 날 따로 켠 방송을 고르는 목록의 오른쪽에는 ‘시작’을 빼고 ‘20:00’처럼 시각만 표시한다.

## 1.9.45 · 1건

1. 분할 다시보기에서 이미 확인한 부 번호를 기억한다. 1부가 비공개로 바뀌어도 남은 영상은 2부·3부로 표시한다.

## 1.9.44 · 2건

1. 1부가 비공개가 돼 2부만 남은 경우에도 주간 선택 목록에 원래 방송 시작 시각을 표시한다.
2. 최근 활동과 홈 요약을 방송 시작·글 작성 시각순으로 정렬하고, 해당 시각이 없는 예전 기록에는 저장된 활동 시각을 사용했다. 이후 1.9.46에서 발견 시각순으로 바꿨다.

## 1.9.43 · 3건

1. 최근 활동과 주간 발자국이 같은 공개 영상의 제목·원래 방송 시작 시각·영상 번호를 사용해 어느 쪽에서 눌러도 같은 다시보기를 연다.
2. 원본 방송 번호가 같은 분할 영상은 자정을 넘겨도 한국시간 방송 시작일에 묶고, 새로 켠 방송은 별개의 방송으로 둔다.
3. 분할 다시보기 목록에 각 부의 제목과 확인 가능한 시각을 표시하고, 자정을 넘긴 부에는 ‘다음 날’을 붙인다.
