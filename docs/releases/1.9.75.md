# 1.9.75 배포 기록

2026년 11월 26일 Chrome 웹스토어에 제출한 확장 프로그램이다. 제출 시점의 공개 버전은 1.9.42였고, 1.9.75는 검토 통과 후 자동 게시로 접수됐다. 현재 스토어에서 설치할 수 있는 버전은 [스토어 항목](https://chromewebstore.google.com/detail/mojidkfjenpknjimjfobjnpgafceakpc)에서 확인할 수 있다.

## 1.9.42에서 달라진 점

- 최근 활동의 **소식 바구니**에서 방송·치지직·디스코드를 바로 골라 볼 수 있다. 뒤늦게 발견한 소식은 발견한 날에 모이고, 실제 방송 시작일은 주간 발자국에 남는다.
- 최근 활동과 발자국이 같은 다시보기 제목·시각·링크를 사용한다. 같은 방송으로 확인된 1부·2부는 방송을 시작한 날에 묶이고, 자정을 넘긴 부에는 ‘다음 날’이 붙는다. 일부 영상이 비공개가 돼도 이미 확인한 부 번호는 유지한다.
- ‘지금 확인’, 룰렛 갱신·복사, 백그라운드 열기의 진행 상태와 결과를 구분하기 쉬워졌다. ‘잠시 쉬기’는 5분 단위 슬라이더와 빠른 시간 선택을 제공한다.
- 방송 시작·놓친 방송 알림에서 배너를 누르면 어디로 이동하는지 안내한다. 새 글 알림 설정 시 예약 복구 안내가 잠깐 나타나던 현상과 좁은 팝업에서 설명이 어색하게 줄바꿈되던 부분을 다듬었다.

## 제출 파일 확인

[릴리스의 설치 ZIP](https://github.com/jqu8ry/kkosunnae-tracker/releases/download/v1.9.75/kkosunnae-tracker-1.9.75.zip)은 제출 파일의 이름만 바꾼 사본이다. 루트에 `manifest.json`이 있으며 크기는 1,190,319바이트다. 태그의 [extension 폴더](../../extension/)에는 같은 26개 파일이 있다. GitHub가 별도로 제공하는 ‘Source code’ 압축에는 저장소 문서와 홈페이지도 함께 들어간다.

SHA-256은 `8c542fd6a7ad1369c0c05a0c2f3dd197087a890eb03874b40aab061073ff0b63`이다. Windows PowerShell에서 받은 파일을 확인할 수 있다.

```powershell
Get-FileHash -Algorithm SHA256 .\kkosunnae-tracker-1.9.75.zip
```
